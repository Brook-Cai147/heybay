    ② **空字符串不等于留空**。Prompt 要求"判断不了就留空"，模型回 `""`，却被判成"枚举值不在白名单"。「留空」在 JSON 里有三种写法（缺字段/null/空串），校验器只认前两种。

  - 顺带补了两处：重试时把上一次的字段级错误回喂给模型（原来是原样重发，等于白花一次钱）；嵌套对象的 warning 冒到最外层（否则被剥掉的键悄无声息）。
